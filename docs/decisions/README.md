# Journal des décisions (docs/decisions/)

Le Plan (0.2, 10.2, fin du document) demande que toute décision qui s'en écarte, ou qui tranche un silence, soit consignée par écrit, datée et motivée dans ce dossier. La mission demande le même journal dans `pilotage/journal_des_decisions.md`.

Pour éviter deux sources qui divergent, le journal tenu à jour est **pilotage/journal_des_decisions.md** ; ce dossier en garde une copie datée à chaque fin de tranche, ainsi que les dossiers de décision détaillés :

- `journal-tranche-01.md` : copie du journal à la fin de la tranche 1 ;
- `pile-technique.md` : vérification des versions 10.2 (règle de gel) ;
- `moteur-voix.md` : essai comparatif des voix 7.5 et licences (tranche 2).
